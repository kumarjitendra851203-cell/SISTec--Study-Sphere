EduSync — SISTec GN Bhopal

Files:
- index.html: page structure and external library imports
- styles.css: extracted styles and responsive layout
- script.js: extracted application logic and demo data

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser, or use VS Code Live Server.
3. The app currently uses demo/local browser data; real authentication, cloud storage,
   and server-side AI headcount detection require a backend/service setup.
