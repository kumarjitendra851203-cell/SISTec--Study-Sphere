EduSync is a web-based college management and student learning platform designed around the academic needs of **Sagar Institute of Science and Technology — Gandhi Nagar (SISTec GN), Bhopal**.

The platform brings student learning resources, quizzes, academic performance, placement opportunities, campus bus information, and classroom headcount tools together in one convenient interface.

## 🌐 Live Demo

**Website:** https://sistec-studysphere.vercel.app/

**Deployment:** Vercel

## ✨ Features

### 👨‍🏫 Teacher Dashboard
- Teacher-oriented dashboard and overview
- Classroom headcount tools
- Upload study resources and assignments
- Create and publish quizzes
- View student quiz results
- Post placement opportunities

### 👨‍🎓 Student Dashboard
- Access the Study Hub
- Explore available quizzes
- View quiz scores and performance
- Browse the study library
- Bookmark and find learning resources
- Access placement information and bus routes

### 📚 Study Resources
- Upload and organize learning materials
- Support for PDF files, images, and assignments through the resource interface
- Search available study resources
- Organize materials by subject and type

### 📝 Quiz Management
- Create quizzes with questions
- Publish quizzes for students
- Attempt available quizzes
- Review answers and scores
- Track academic performance

### 💼 Placement Bulletin
- View placement opportunities
- Browse company and job-role information
- Review package and eligibility details
- Search and filter opportunities

### 🚌 Campus Bus Information
- Access SISTec GN bus-route information
- View transport contact details
- Find campus transport information in one place

### 📊 Headcount Tools
- Classroom headcount interface
- Class selection and student-count adjustment
- Headcount logging interface
- Photo-based headcount workflow

*Note: Actual AI-based detection and data persistence depend on the implemented application logic and backend integrations.*

## 🎯 Project Objectives

- Bring useful academic tools into one platform.
- Make learning resources easier to access.
- Simplify quiz creation and assessment.
- Help students explore placement information.
- Make campus transport information easier to find.
- Explore digital solutions for classroom headcount management.
